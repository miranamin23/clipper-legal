Clipper.js

A local desktop tool that turns long videos into short vertical clips with burned-in subtitles.

What it does

  • Transcribes a video on your own machine and generates word-timed subtitles.
  • Finds clip-worthy segments and renders them as 9:16 MP4 files.
  • Prepares a caption and hashtags for each clip.
  • Optionally uploads a finished clip to your own TikTok account as a draft, which you then review and post yourself in the TikTok app.

How it runs

Clipper.js runs entirely on the user's own computer at 127.0.0.1. There is no hosted service, no account system and no backend that receives user videos. Transcription and video rendering happen locally.

TikTok integration

The app uses TikTok's Content Posting API in upload-to-inbox mode. It only ever uploads files that the user explicitly selects, and only to the TikTok account the user has connected. Uploaded videos arrive as drafts; nothing is published automatically.
