Privacy Policy

Clipper.js · last updated 27 July 2026

Clipper.js runs entirely on the user's own computer. It operates no servers, collects no analytics, and transmits no personal data to the author.

1. Data processed locally

All processing happens on the user's machine. The following stays on that machine and is never transmitted to the author or any third party:

  • Video and audio files the user imports.
  • Transcripts generated from those files.
  • Rendered clips, captions and project settings.

2. TikTok account data

If the user chooses to connect a TikTok account, the software requests these permissions:

  • user.info.basic — to display the connected account's name so the user can confirm they are uploading to the right account.
  • video.upload — to upload a selected video to that account's drafts.

The resulting access and refresh tokens are stored in a file on the user's own computer. They are not sent anywhere except to TikTok's own API endpoints. Uploads go directly from the user's computer to TikTok.

3. What is not done

  • No analytics, telemetry, tracking or crash reporting.
  • No cookies and no advertising.
  • No selling or sharing of data — there is no data to sell.
  • No reading of TikTok content, followers, messages or other account data beyond the basic profile name.

4. Third parties

When the user connects an account or uploads a clip, data is exchanged directly with TikTok, governed by TikTok's own privacy policy. When the user imports a video by URL, the request goes directly to the platform hosting that video.

5. Retention and deletion

Because all data is local, the user controls retention entirely. Disconnecting the TikTok account inside the software deletes the stored tokens. Deleting the application folder removes all remaining data. Access previously granted can also be revoked at any time in the TikTok app under Settings → Security and permissions → Manage app permissions.

6. Children

The software is not directed at children under 13.
